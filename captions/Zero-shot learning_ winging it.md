🧠 Techie Deep Dive:
Zero-Shot Learning (ZSL) is the ability of an AI model to correctly classify data from classes that it has never seen during training.

How is this possible? The key is to learn a shared semantic space between the visual data and textual descriptions.
1.  The model is trained on images of seen classes (e.g., cats, dogs) and their corresponding labels.
2.  Crucially, it's also given semantic information about both seen and *unseen* classes (e.g., textual descriptions of their attributes). For example, it knows a "cat" has fur, whiskers, and pointy ears, and a "zebra" (an unseen class) is a "horse with stripes."
3.  When presented with an image of a zebra, the model extracts its visual features (four legs, horse-like shape, stripes) and finds the unseen class whose semantic description best matches those features.

ZSL is a step towards more general AI that can handle novelty and learn more like humans do.

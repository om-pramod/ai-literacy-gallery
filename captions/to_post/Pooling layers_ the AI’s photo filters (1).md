🧠 Techie Deep Dive:
Pooling Layers are a common component in Convolutional Neural Networks (CNNs), which are primarily used for image processing.

1.  Purpose: The main purpose of a pooling layer is to downsample the feature maps from the previous convolutional layer. This means it reduces the spatial dimensions (width and height) of the representation.
2.  How it Works: The most common type is Max Pooling. The layer slides a small window (e.g., 2x2 pixels) over the input, and for each window, it outputs only the maximum value.
3.  Benefits:
• Reduces Computational Cost: By making the representations smaller, it reduces the number of parameters and computations in the network.
• Provides Invariance: It makes the model more robust to small translations or distortions in the image. If an object moves slightly, the max pooling output is likely to remain the same.
